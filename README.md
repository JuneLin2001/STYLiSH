### Tech Stack

- Built with **HTML, CSS, JavaScript** and **React** to ensure stability and reliability.
- Followed **Figma** design mockups for precise and responsive layouts.
- Implemented product search via **Backend API calls** to provide users with quick and accurate results.
- Hosted on **Firebase Hosting** for reliable performance and scalability.
